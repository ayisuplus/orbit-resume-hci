# ORBIT 交互验证 V2

2026-10-11，根据用户试用 V1 后的实际反馈修改。保留 `../V1/` 原版。本版本仍使用待填写简历内容，尚不属于最终可提交作业。

## 运行

双击 `启动预览.cmd`，打开 `http://127.0.0.1:4174`。也可使用 Node.js 执行 `node server.mjs`。按 Ctrl+C 关闭预览服务。

Three.js 0.186.1 已包含在 `vendor/`，附 MIT LICENSE；来源及校验值与 V1 相同。网页运行不请求 CDN。本版本可独立运行，原 V1 服务使用 4173 端口。

## 本轮评审与修改

反馈来源：用户本人在当前聊天中查看并评价 V1。此记录是设计者评审，不冒充课程要求的两名外部用户可用性测试。

| 用户反馈 | V2 修改 | 验证方式 |
| --- | --- | --- |
| 魔方有点小，放大一点 | 模型比例增大 30%，调整相机距离并增高展示区域，实际屏幕占比进一步增加 | 桌面及 390px 手机视口截图 |
| 环像一个框围着卡片，内容应更像贴在环上 | 去掉独立外围框、卡片背景与圆角；用 60 个窄面组成连续圆柱表面，与内容同父级转动，加入俯视倾角；正文保持 HTML，可读可选 | 浏览器实际切换及停稳截图 |
| 颜色单调，魔方应该是彩色 | 魔方使用红蓝黄绿橙白六色；五个简历模块使用青紫粉金绿主题，环面分区与顶部选中状态呼应 | 实际画面检查 |
| 应有上下左右翻转，每次快一点 | 交替绕 X/Y 轴做整圈翻转，反向切换改变方向，保留分层错转；时长从 850ms 降为 560ms | 浏览器操作及动画状态验证 |

## 已做技术检查

- app.js、server.mjs 的 Node 语法检查通过。
- 内置浏览器桌面和 390px 窄屏：五个入口均对应正确模块，每次仅一个可访问面板，无横向页面溢出。
- 实际浏览器出现彩色魔方、连续彩色环面，切换到目标模块后能停稳。
- 对 app.js 中实际状态与动画函数使用虚拟 DOM/时钟验证：100 组中断序列最终落到固定姿态；同目标点击不改动画起点和目标；减少动态效果时立即结束。
- 独立 subagent 发现同目标重复点击重启动画的问题，已修复并获只读复核；3D 初始化也不再重启动画。
- 当前浏览器检查未捕获 console error/warn。

截图在 `验证/`。上述技术检查不能替代外部用户测试。真实手机、Safari/Firefox、真实用户阅读体验、Figma 源文件及完整报告仍待完成。
