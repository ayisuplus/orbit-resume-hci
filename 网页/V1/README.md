# ORBIT 交互验证 V1

依据用户提供的魔方与环形简历草图，于 2026-10-11 制作。目标岗位为软件开发工程师。当前是交互验证版，个人资料均待填写，不是可直接提交的最终简历。

## 运行

需要 Node.js。双击 `启动预览.cmd`，在浏览器打开 `http://127.0.0.1:4173`。也可在本目录运行 `node server.mjs`。关闭服务窗口或按 Ctrl+C 停止。不要直接双击 HTML，浏览器本地文件策略会影响模块加载。

Three.js 0.186.1 存在本地 `vendor/`，页面运行时无需 CDN。来源为 npm 包 `three@0.186.1`，由 jsDelivr 分发，附原 MIT LICENSE。第一方界面使用 HTML/CSS/JS，魔方由 Three.js 绘制，信息环为 CSS 3D 布局。服务仅监听本机。

## 交互与验收

- 魔方及左右按钮顺序切换五个模块，顶部导航直接跳转。
- 五个模块分别对应固定魔方姿态；过渡由同一页面选择触发，最后一次点击决定最终状态。
- 正文是可选择、可阅读的 HTML，非当前面板不进入键盘焦点与辅助阅读顺序。
- 系统设置“减少动态效果”时直接切换，空闲时不持续渲染。
- WebGL 不可用时显示替代切换符号，正文及导航仍可使用。
- `#about`、`#education`、`#projects`、`#skills`、`#contact` 可定位模块。

本次实现不能替代 Figma `.fig` 源文件、真实访谈与外部用户测试。原型与最终 V2 应根据实际评审和反馈形成，保留当前版本。
