## 这是什么

一个网页版个人简历：上方一个可点击的魔方，下方一圈环形信息带，五个内容模块
（个人简介 / 教育背景 / 项目经历 / 专业技能 / 联系方式）分别对应魔方的五个固定姿态。

点击魔方、点顶部导航、点前后按钮——三条路径都通向同一个状态源，
由一个 `current` 索引统一驱动，不会出现"魔方转了但栏目没换"的状态不同步。

## 技术栈

| 部分 | 实现 |
| --- | --- |
| 魔方 | Three.js 0.186.1（本地 `vendor/`，运行时不依赖 CDN） |
| 环形信息带 | CSS 3D transforms，60 个窄面组成连续圆柱面，与正文共享旋转父级 |
| 状态与动画 | 原生 JavaScript ES modules |
| 页面 | 语义化 HTML5 + CSS，`inert` / `aria-hidden` / `aria-current` 处理面板与导航 |

## 运行

需要已安装 [Node.js](https://nodejs.org/)。

```bash
cd 网页/V2
node server.mjs
# 或双击 启动预览.cmd
```

然后打开 `http://127.0.0.1:4174`（V1 为 4173 端口）。
直接用浏览器打开 `index.html` 也能看，但 ES modules 在 `file://` 下会被 CORS 拦截，
所以推荐走 `server.mjs`。

## 设计过程要点

- **五个固定姿态，不做可操作魔方**：完整魔方操作过重，与求职任务无关，固定五态保证"点一下必达"。
- **环面与内容共享旋转父级**：早期版本里环像独立外框围住卡片，去掉独立边框与卡片背景、
  改成 60 面连续圆柱面后，"内容贴在环上"的空间关系才成立。
- **不靠颜色单独传达信息**：导航同时用文字、序号、边框和颜色标识当前模块
  （窄屏 ≤760px 时序号按媒体查询隐藏，保留文字与边框）。
- **无障碍**：正文保留在 DOM 中（可选中、可搜索），非当前面板 `inert`，
  支持键盘焦点、跳过场景入口、`prefers-reduced-motion`；
  WebGL context lost 时魔方退化为占位符号，正文与导航仍可用。

## 迭代记录

V1 实际运行后由本人提出 4 条反馈，均在 V2 落地并有验证记录：

1. 魔方偏小 → 模型比例增大 30%，调整相机距离并增高展示区域
2. 环像独立框架围住卡片 → 去掉独立外围框与卡片背景，改 60 窄面连续圆柱面，与内容同父级转动
3. 颜色单调 → 魔方红蓝黄绿橙白六色，五个模块青紫粉金绿主题色
4. 翻转方向和节奏不够丰富 → 交替绕 X/Y 轴整圈翻转，保留分层错转，动画 850ms → 560ms

快速连续点击时，新的一次切换从**当前显示姿态**继续插值（展开角度 unwrapped angle），
而不是重置回初始位再转。用 100 组中断切换序列验证过最终都落在目标固定姿态
（虚拟时钟 + 虚拟 DOM 跑 `app.js` 状态与动画函数，非真浏览器自动压测）。
